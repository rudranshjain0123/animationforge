# Classic catalog audit

I rendered all 125 classic presets on light and dark surfaces in Chromium, sampling two points in each animation. The main library now contains 23 new presets with a concrete website use case. The classic IDs and settings remain readable so saved projects and favorites still work.

Reproduce the contact sheets with `node browser/contact-sheet.js /tmp/af-classic --classic` and `node browser/contact-sheet.js /tmp/af-studio`.
